# AI Agents — Knowledge Base Setup
**Route:** `/agents` (Knowledge Base tab)

1. Click **"+ Add Knowledge Source"**.
2. Select your data source type:
   - **Upload Documents**: Upload company PDF catalogs, product brochures, or price lists.
   - **Website / URL Crawl**: Enter your website URL or FAQ link for automatic indexing.
   - **Q&A FAQs**: Enter custom question-and-answer pairs directly.
3. The system automatically chunks and indexes your content into vector embeddings for retrieval.
