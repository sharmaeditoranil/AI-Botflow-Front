# Contacts & Audience Management
**Route:** `/contacts`

### Adding & Importing Contacts
- **Single Contact**: Click **"+ Add Contact"** and enter Name, WhatsApp Number (with international country code e.g., `919876543210`), Email, and Tags.
- **CSV Bulk Import**:
  - Click **"Import CSV"**.
  - Download our sample CSV template.
  - Upload your file containing columns: `name`, `phone`, `email`, `tags`, and any custom fields.
  - Preview and map columns, then click **"Start Import"**.

### Tags & Segmentation
- Create tags (e.g., `VIP`, `Lead`, `Paid Customer`, `Follow-up Required`) to categorize customers.
- Tags can be applied in bulk from the Contacts table or added individually directly inside the Live Chat Inbox.
- Filter contacts by tags to create laser-targeted broadcast audiences.

Custom attributes (fields) for contacts are managed on a separate page — see Custom Fields Settings.
