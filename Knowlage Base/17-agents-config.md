# AI Agents — Configuring the AI Agent
**Route:** `/agents` (Config tab)

- **System Prompt / Persona**: Define the AI's identity (e.g., *"You are the friendly sales concierge for AI Botflow. Your goal is to answer customer questions accurately using only the knowledge base and encourage them to book a free demo."*).
- **Fallback Rule**: Define behavior when information is not in the knowledge base (e.g., *"Connect you with our human team"*).
- **Temperature**: Control creativity (0.2 for strict factual support, 0.7 for conversational sales).
- **Auto-Reply Toggle**: Turn auto-reply ON for all incoming chats or restrict it to unassigned leads.
